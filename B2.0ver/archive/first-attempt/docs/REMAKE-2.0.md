## 動態與切換

- 頁面淡入 0.5 秒；情境卡片錯開進場，捲動換卡 0.8 秒。
- 左欄三張數據卡與右欄解方同步依光照 → 空氣 → 溫濕度 → 聲音切換，每個維度 5 秒。
- 圖表長條、色溫、舒適區間、聲景波形依情境資料更新。數字 1.3 秒遞增至目標值。
- 感應漣漪於 1.8 秒後移除；新感應不會被舊漣漪回呼清掉。
- 四種已體驗時不自動收尾；第五種仍完整展示 20 秒才進結語，結語 9 秒後清空本輪。
- 前言為選播頁：聲紋與 3／2／1 倒數，之後使用 N 繼續。

## 相對初代的必要調整

1. 獨立根目錄、5284 埠、2.0 視窗標題及 `b2:` 設定鍵；不共享初代 node_modules 或儲存設定。
2. 還原截圖左下的替代 NFC 卡片控制；五列情境可以滑鼠、觸控或鍵盤啟動。
3. 預設不連實體 NFC，以免兩版同時預覽時互相觸發；啟用方式記載於 README。
4. 邀請卡連續回報不反覆重啟；真正的新一次邀請會重新掛載資訊牆並重啟其前導計時。
5. 情境完成事件附播放序號，快速換角色情況下拒絕過期回呼。
6. 小數數據依原始精度顯示，0.05、0.03 不被一位小數四捨五入掩蓋。
7. 將實際流程與節拍拆出為可測模組；保留原視覺與動畫元件架構。
