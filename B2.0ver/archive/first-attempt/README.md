# 感應光寓 2.0 · B 區介面系統

本機重製版本位於 `/Users/chunming/B2.0ver`。以 `2.0參照畫面/` 的 7 張初代截圖及 `/Users/chunming/B/B-TV` 原始程式為依據，保留視覺、素材、配色、版面及動態流程。初代資料夾未修改。

## 開啟

雙擊 `啟動-B2.0.command`，或在此資料夾執行：

```sh
npm ci
npm run dev
```

開啟 http://127.0.0.1:5284/ 。重製版固定使用 **5284**；初代 **5274** 不受影響。頁面名稱與設定儲存鍵均獨立標記 2.0；所有 localStorage 使用 `b2:` 前綴。

## 展演流程

```text
待機：感應光寓、曲線光束
  └─ 感應邀請卡 C → 房屋即時健康資訊牆
       └─ 前導音檔播完／靜音 20 秒 → 五種情境選項
            └─ 情境 1–5 → 對應的三欄動態資料牆
                 光照 5 秒 → 空氣 5 秒 → 溫濕度 5 秒 → 聲音 5 秒
                 ├─ 尚未集滿五種：留在目前情境循環展示，可切換其他情境
                 └─ 已集滿五種：最後一輪完整播完 → 結語 9 秒 → 待機
```

情境為居家抗老、兒童免疫、在宅樂齡、孕婦照護、數位遊牧。各情境保留不同欄寬、色塊、痛點高度、照片／影片及四組解方內容。前言聲紋與倒數頁保留為展務員手動入口，不插入主流程。

## 操作

左下角「替代 NFC 卡片」可展開邀請卡、五種情境與流程控制；選項頁的五個情境也能直接點擊。面板顯示本輪已體驗數量。

| 按鍵 | 動作 |
|---|---|
| C | 感應邀請卡，開始新訪客流程 |
| 1–5 | 感應對應情境 |
| N / → | 前言進入資訊牆；資訊牆提前進入選項 |
| I / Enter | 選播前言聲紋與倒數 |
| O | 提前播放結語 |
| R / Esc | 回待機並清除本輪體驗 |
| X / Space | 拿起卡片，保留目前展示 |
| E | 初代版面／配色調整工具，僅儲存在 2.0 |

`?kiosk=1` 隱藏替代 NFC 面板，鍵盤操作仍可用。

## 實體 NFC

預設為**本機預覽模式**，不連線、不廣播到初代的 NFC server。要接現場硬體，開啟 `http://127.0.0.1:5284/?hardware=1`，或按 `.env.example` 設定後重新啟動。

支援原有 `reader-connected`、`reader-disconnected`、`tag-present`、`tag-remove`、`reset`、`intro`、`outro` 協議。啟用硬體後，模擬按鍵也會發送給 server 並由其廣播同步。NFC server 本身不在本資料夾內。

同一張卡持續留在讀卡機時不重啟邀請流程；拿起後再刷視為新邀請。同情境連續回報不重播、不重複計數；換到其他情境再回來可重播。快速換情境時，舊播放完成事件不會提前結束新情境。

## 素材與待接項目

- 已保留初代本地字體、商標、主視覺、四張情境照片及房屋導覽影片。
- 孕婦情境沿用參照中的導覽影片，不另造替代照片。
- 八個正式配音檔未提供；目前依初代設定靜音。音檔放至 `public/voice/`，再於 `src/speech.js` 啟用。資訊牆有 20 秒退路及 120 秒播放逾時保護。
- 資訊牆與解方數值是初代展示資料，尚未接真實感測器；WELL 分數亦為展示內容。
- 提供的 Claude 規劃連結於 2026-09-08 顯示「Sign in to view this page」，尚未能核對其整體規劃。當前範圍依據本機可讀的 TV 介面與規格，未聲稱已完成未知的桌面投影／後端部分。
- 機位編輯工具保留為初代附屬工具；主流程使用照片／影片，本機未提供正式 3D 房屋模型。
