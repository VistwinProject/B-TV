正式程式位於 `app/`，入口是 `app/main.jsx`。依初代畫面與流程規格重新實作，沒有匯入初代元件、CSS、狀態機或動畫程式。

初次「複製後修改」的嘗試已停用，保留於 `archive/first-attempt/`，不參與正式建置。原始初代 `/Users/chunming/B/B-TV` 未修改。

## 使用

雙擊 `啟動-B2.0.command`，或執行：

```sh
npm ci
npm run dev
```

預覽： http://127.0.0.1:5284/ 。2.0 使用獨立埠號 5284；初代仍為 5274。新版不讀取初代或第一次嘗試的 localStorage。

左下角「替代 NFC 卡片」可展開控制。C 開始邀請流程，1–5 切換情境，N 提前進入下一頁，I 選播前言，O 提前結語，R / Esc 回待機，X / Space 拿起卡片。選項頁五列也能直接點擊。

## 流程

```text
待機 → 邀請卡 → 房屋資訊牆 → 五種情境選項
                               ↓ 情境鑰匙圈
                     光照 → 空氣 → 溫濕度 → 聲音
                      每維度 5 秒，一輪 20 秒
                               ↓
        尚未集滿五種：保持目前情境循環，可繼續換情境
        五種都已感應：最後一輪完整播完 → 結語 9 秒 → 待機
```

資訊牆在前導音檔播完後進入選項；未啟用語音時停留 20 秒。前言聲紋頁是展務員選播入口，並未插入主流程。

垂直換卡保留進出兩張面板，在 0.8 秒後清除舊面板。數字以 requestAnimationFrame 更新文字。場景節奏由經過時間計算，不依賴動畫結束回呼；五種都感應過後，最後一輪完整結束才收尾。語音回呼帶畫面版本號，離開頁面時會停止播放並清除音訊資源。

## 沿用與重寫界線

**沿用內容：** 7 張參照圖中的文案、數值、色碼、欄寬；四張情境照片、樣品屋影片、字體、ANLB 品牌圖示。這些是展覽的內容與設計素材，不是初代程式元件。

**重新實作：** 所有正式入口程式、介面元件、CSS、換頁控制、定時器、圖表呈現、數字與捲動動畫、聲紋、NFC 接收與替代卡片面板。

2.0 已獨立實作 E 佈展編輯器（`app/editor/`），不匯入初代編輯程式。正式流程使用照片／影片；初代的 3D 機位工具仍僅保留在封存參考程式中。

## 硬體與語音

預設是本機預覽，不會向初代 NFC server 廣播。`?hardware=1` 或 `VITE_NFC_ENABLED=true` 可啟用硬體連線；URL 由 `VITE_WS_URL` 設定，預設 `ws://localhost:8788`。`?kiosk=1` 隱藏替代卡片面板。

NFC 協議維持 `reader-connected`、`reader-disconnected`、`tag-present`、`tag-remove`、`reset`、`intro`、`outro`。硬體開啟且已連線時，模擬輸入會傳送給 NFC server，再透過其廣播同步。

正式 MP3 檔放入 `public/voice/`，再設定 `VITE_AUDIO_ENABLED=true` 並重啟。檔案命名見該資料夾 README。播放失敗時資訊牆回到 20 秒計時，成功播放但未收到結束事件時有 120 秒保護。

## 資訊卡內容與圖示動態（2026-09-08）

五種情境依「截圖 2026-09-08 下午2.31.50.png」更新：核心目標、光照、空氣、溫濕度、聲音。所有門檻保留 ≤／≥／<／~、原始小數精度及單位。移除舊室內外 PM2.5、65 dB 對比，以及未出現在新圖表的健康分數。

各情境的五個資訊圖示及角色圖示均有動態：燈光依指定 K 值或光照類型緩慢呼吸；氣流線與粒子拂動；水滴及蒸氣上升；溫度計液柱升降並由藍轉紅；聲音等化器起伏；核心目標環轉動。圖示是循環示意，資訊卡上的設定值不會被動畫改動。系統偏好減少動態時顯示靜態版本。

色溫僅孕婦 1800–2700K、數位遊牧 5000–6500K 依明確數值計算；其他情境按圖示的暖光／冷光／全光譜描述呈現，不虛構 K 值。濕度卡使用水氣圖示；未指定濕度的老人、數位遊牧情境不再顯示舊版濕度數值。

## E 編輯面板（2026-09-09）

按 **E** 或點選畫面下方「E · 編輯畫面」開啟；按 **E／Esc** 或「完成編輯」關閉。面板頂列可拖曳移動，也可收合。文字輸入時 E 不會誤觸切換。

- 預覽六個介面、五種情境及各情境四個維度；編輯預覽不計入已體驗角色。
- 情境：七個配色位置、三欄比例、痛點卡高度；欄寬與高度可拖曳或以滑桿調整，版面可套用至五種情境。
- 資訊牆：六欄四列比例、十張卡片的配色／透明／邊框。
- 待機：背景與文字色、三個光束控制點、各點寬度、光暈與亮邊強度。
- 五情境共用材質：情境色／白色／影片背景，平面／玻璃卡片、不透明度、白色覆層、模糊、反光及 SVG 模擬折射。折射為視覺效果，呈現取決於瀏覽器的 backdrop-filter 支援。
- 自動儲存於本機瀏覽器 `b2:editor:v1`，與初代分開；可匯出／匯入 JSON、復原上一步、重設當前畫面或全部設定。匯出檔可帶到另一台裝置匯入；設定不會自動改寫原始碼。

編輯時展演時間及 NFC 換頁暫停；關閉後回到原本的展演頁與剩餘時間。卡片圖示持續播放動態。若開啟語音，編輯會停止音檔，完成後從目前頁的音檔開頭重播。直向版面保持閱讀順序，隱藏拖曳分隔線；橫向展演可完整預覽比例調整。

驗證完成：22 項自動測試與 production build。尚未做瀏覽器拖曳互動及逐像素視覺驗收。
